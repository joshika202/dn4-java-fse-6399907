1.Define SPA and its benefits

A Single Page Application (SPA) is a web app that loads a single HTML page and dynamically updates the content using JavaScript as the user interacts with the app.

*Benefits of SPA:
Faster load times after the first load
Seamless user experience
Reduces server load
Easy to debug with Chrome or Firefox dev tools

2.Define React and identify its working

React is an open-source JavaScript library developed by Facebook for building fast and interactive user interfaces for web and mobile applications.

*How it works:
Uses components (reusable UI blocks)
Manages views with state and props
Uses virtual DOM to update only necessary parts of the actual DOM

3.Identify the differences between SPA and MPA
Feature	    SPA (Single Page App)	    MPA (Multi Page App)
Loading	    Loads once	                Loads every time you change page
Speed	    Faster (after initial load)	Slower due to page reloads
Development	More JS logic	            More backend/server logic
Examples	Gmail, Facebook	            Amazon, Wikipedia

4. Explain Pros & Cons of SPA
Pros:

Faster interactions

Better user experience

Easier to turn into a mobile app using frameworks like React Native

Cons:

SEO limitations (harder for search engines to crawl)

Can be complex to implement authentication and routing

Initial load can be heavy


5. Explain about React
React is a component-based JavaScript library used to build user interfaces, especially for single-page applications. It is known for its declarative programming, efficient rendering using virtual DOM, and reusability through components.

6. Define virtual DOM
The Virtual DOM is a lightweight JavaScript representation of the actual DOM. React uses it to:

Detect changes in the UI

Update only the changed parts instead of re-rendering the whole page

Improve performance and responsiveness

7. Explain Features of React
Component-Based architecture

Virtual DOM for fast rendering

One-way data binding

JSX syntax (JavaScript + HTML)

Unidirectional data flow

Reusable components
